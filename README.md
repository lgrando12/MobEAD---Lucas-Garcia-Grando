# 🚀 Projeto CI/CD com Jenkins, SonarQube e Docker

## 🇧🇷 Descrição 

Este projeto foi desenvolvido como parte da pós-graduação em Engenharia DevOps (Unyleya), com foco em práticas de Integração Contínua (CI) e Entrega Contínua (CD) utilizando Jenkins.

### 🔧 Tecnologias Utilizadas
- Jenkins (Pipelines CI/CD)
- SonarQube (Análise de Qualidade de Código)
- Hadolint (Lint para Dockerfile)
- Docker
- GitHub (Repositório de código)

### 📁 Estrutura do Pipeline
1. Build com validação de `Dockerfile` via Hadolint
2. Análise de código com SonarQube
3. Deploy condicional para ambiente de desenvolvimento e produção

### 🌐 Ambientes
- **DEV:** http://localhost/dev  
- **PROD:** http://localhost/prod

### 🖼️ Prints Disponíveis
- Pipeline configurada no Jenkins
- Execução da análise com SonarQube
- Deploy com parâmetro para produção
- Páginas de DEV e PROD
